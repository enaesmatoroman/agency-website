# Agency Website

Landing page izrađen koristeći HTML i CSS, baziran na dizajnu iz Figme. Projekat predstavlja implementaciju moderne agencijske web stranice sa fokusom na strukturu, dizajn i organizaciju koda.

---

## Features

* Modern UI layout (navbar, hero, services, about i druge sekcije)
* Pixel-perfect implementacija iz Figme
* Organizovan i čitljiv CSS
* Hover efekti i osnovne animacije

---

## Technologies Used

* HTML5
* CSS3

---

## Project Structure

project-folder/
│── index.html
│── style.css
│── /images
│── /assets

## How to Run

1. Kloniraj repozitorij:
   git clone https://github.com/username/agency-website.git

2. Otvori folder:
   cd agency-website

3. Pokreni projekat:

* Otvori `index.html` u browseru
